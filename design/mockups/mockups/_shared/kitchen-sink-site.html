01 / How it works

Screen every call.
Prove only what was asked.

Blindseal sits between an agent and its tools as a local proxy, inspecting every tool call with four layers of prompt-injection detection before the call executes.

Screen

Four layers, on your machine

Deterministic rules first, then the model-based judge, locally or inside a TEE. Secrets and PII are redacted before the judge sees them.

L0 · L1 · L2 · L3

Attest

A single-use stamp

The attestation binds target program, recipient, amount, policy root and expiry, so it is worthless for any other call.

Verify

Any program can gate agent actions without seeing the prompt, the arguments, the operator's rules, or which agent was screened.

A deliberately narrow claim.
